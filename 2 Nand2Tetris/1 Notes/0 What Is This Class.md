When you first started computer science, the very first thing you are usually taught is a programming language, following that is data structures & algorithms.

But, those are just logic on a computer, if this do that, push in push out. You could easily write code in any language, but you can't connect the idea that computers are made up of 0's and 1's, with the programming that you are doing that's akin to english.

And today, there's so many applied fields and niches in computer science, like AI, CGI, websites... (stuff I like personally), but none of them answer the fundamentals of computer science, **what is a computer?**

As the authors themselves wrote:

> [!PDF|yellow] [[The Elements of Computing Systems Building a Modern Computer from First Principles.pdf#page=14&selection=70,67,83,1&color=yellow|The Elements of Computing Systems, Building a Modern Computer from First Principles 2 ed, p.14]]
> > Alas, as digital technologies have become increasingly more complex, this clarity is all but lost: the most fundamental ideas and techniques in computer science —the very essence of the field—are now hidden under many layers of obscure interfaces and proprietary implementations.

Sure, most of our development of programs don't deal with how they literally run as electrical signals on the hardware, but it would still be really funny if a computer science major didn't know how a computer works at the end of the day.

![[0 What Is This Class 1.png|500]]

All computers are equivalent in their logic, from a high level language, to virtual machine code, to machine language, executed by a CPU, carried out by the computer's hardware, which are made up of boolean logic gates, all of which are built on top of transistors.

And our goal is to go from the bottom up in reverse.
