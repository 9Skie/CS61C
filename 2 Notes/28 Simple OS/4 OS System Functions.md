This is totally OS! Why are we talking about this in a computer architecture class...


The computer runs applications as **processes**. A process is a running instance of a program with its own isolated memory space, resources, and system state. Processes are isolated from each other in memory, meaning one process cannot directly access another process's memory or interfere with its execution.

A process can contain multiple **threads**, which are separate execution flows within the same process. Threads share the same memory and resources, but each thread has its own execution state. On a single CPU core, multiple threads do not actually run in parallel; instead, the CPU rapidly switches between them, creating the illusion of concurrency.

Applications cannot directly access hardware resources such as memory, files, or I/O devices. Instead, they communicate with the operating system through **system calls**. A system call is a request from a user program to the OS asking it to perform a privileged operation on its behalf.

For example, an application may request:
- opening a file
- creating a new process
- allocating memory
- communicating with a device

The OS performs these operations in **kernel mode**, where it has full access to the hardware. Normal applications run in **user mode**, where they have restricted access. This separation prevents applications from accidentally or maliciously damaging the system.

To transfer control between user mode and kernel mode, the CPU uses **interrupts and exceptions**.

A system call is a manually triggered transition into kernel mode: the application intentionally requests the OS to perform some operation. The OS handles the request, then returns control back to the application.

Interrupts can also happen automatically, such as timer interrupts generated by hardware. These allow the OS to periodically regain control of the CPU and switch between different processes, allowing many programs to appear to run at the same time.

So the overall relationship is:

```text
Application
    ↓
System call / Interrupt
    ↓
Operating System (Kernel Mode)
    ↓
Hardware resources
```

The OS provides the abstraction that allows many applications to safely share the same hardware, while the CPU provides the mechanisms that allow the OS to enforce this control.
